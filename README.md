# الحقيبة التدريبية: تعرّف على كيان

تطبيق تدريبي للموظفين الذين سيستخدمون كيان، بالعربية فقط حالياً (الإنكليزية لاحقاً). يُبنى بمحرّك التطبيقات العملية نفسه (`renderFlowSite`): في الرئيسية بطاقة لكل وحدة، وتعرض الوحدة شريحة واحدة في الشاشة، مع التالي والسابق وقائمة الشرائح والتقدّم.

وحدات التعريف تستخدم **شرائح المفاهيم** (`rcslide`)، لا بطاقة «من؟/أين؟/نفّذ» (`rcquick`) التي تبقى للتطبيق العملي. الشريحة فكرة واحدة: عنوان، ورسالة بسطر، ورسم يناسب الفكرة، وخلاصة، وروابط «تعمّق أكثر» إلى الدليل المختص في تبويب جديد:

```latex
\begin{rcslide}{العنوان}
\sphase{المرحلة} \slead{الرسالة بسطر}
\squote{سؤال أو عبارة بارزة}
\scompare{قبل}{بند \\ بند}{بعد}{بند \\ بند}
\scard{icon}{عنوان}{نص}        % بطاقات متتالية = شبكة واحدة
\schain{أ ← ب ← ج}             % سلسلة تُقرأ من اليمين إلى اليسار
\smetric{المقياس}{قبل}{بعد}     % مقاييس متتالية = صف واحد
\stake{الخلاصة} \slink{guide}{label}{ar/page.html}
\end{rcslide}
```

الأيقونات: `mail chat sheet paper people tasks projects chart entity form flow ai lock gov heart building link` (`SLIDE_ICONS` في `main/tools/html-render.mjs`). الأسهم كلها مرسومة بـCSS وتشير إلى اتجاه القراءة؛ لا تستخدم المحرفين ‹ › لأن المتصفح يعكسهما في النص العربي.

أسئلة التقييم بـ`\squiz{السؤال}{خيار \\ خيار}{رقم الصحيح}{السبب}`: تُعرض الخيارات، ويكشف «اعرض الإجابة» الجواب ويلوّن الخيار الصحيح (عنصر `details` أصلي، بلا JavaScript).

«الصورة الكبيرة» لم تعد وحدة مستقلة: ترابط التطبيقات تشرحه الشريحة الأخيرة من الوحدتين 2 و3، وترتيب أدوات البناء الشريحة الأخيرة من الوحدة 4.

تغطي الوحدتان 2 و3 كل تطبيق جاهز في قائمة التطبيقات (`src/utils/sidebarItems.tsx`): الرئيسية، البريد الإلكتروني، المحادثات، التقويم، مكتبة الملفات، المهام، طلبات الموافقة، الموارد البشرية، الاستراتيجية والتنفيذ، المراسلات، دليل الإجراءات، نتائج الذكاء الاصطناعي، خطط التكليف، تقييماتي، الإعلانات، الإعدادات. أُهملت «الطلبات» (`/submissions`) عمداً لأن صفحتها تعلن إيقافها. لا يوجد في كيان اجتماع فيديو مدمج؛ الاجتماع عبر الإنترنت رابط خارجي في حدث التقويم.

المصادر: الأفكار والمسارات من ملخصات فصول الدليل الرئيسي (`main/tools/chapter-overviews.mjs`) ومقدمات فصول دليل أدوات البناء. وتطبيقات التواصل والعمل اليومي ودليل الإجراءات ونتائج الذكاء الاصطناعي من الشيفرة ونصوصها العربية (2026-11-24)، ولا صفحات لها في الدليل الرئيسي بعد. وأُكّدت عناصر الصفحة الرئيسية بلقطة من test2 (قراءة فقط). لم تُجرَّب الميزات نفسها حياً ضمن عمل الحقيبة.

## الأوامر

من مجلد `guides/`:

```powershell
npm run build:training     # يبني site/
npm run dev:training       # معاينة على http://127.0.0.1:4326/ar/
npm run test:training      # فحوص البناء والطول والروابط
npm run verify:training    # فحص المتصفح (Edge) وصور في review/screenshots
```

## ملاحظات

- `\qlink{guide}{label}{page}` يضيف الروابط نفسها إلى خطوات `rcquick` في التطبيقات العملية.
- الأدوات في `tools/` نسخ من `main/tools` يحدّثها `node sync-reader.mjs`؛ ما عدا `build-html.mjs` و`serve-html.mjs` والفحوص فهي خاصة بالحقيبة.
- `\qlink` يقبل معرّفات `guide-links.mjs` (`main`, `builder`, `inspection`, `correspondence`, `sop`). الفحص يتأكد أن كل صفحة مرتبطة موجودة في `site/` الدليل المعني.
- بطاقة الحقيبة في «تطبيقات الدليل» موسومة «قريباً» (`soon: true` في `GUIDE_APPS`) حتى تُنشر على `https://kayan-training.onrender.com/` (العنوان مؤقت في `guide-links.mjs`).
- لم يُنشأ مستودع git ولا خدمة Render للحقيبة بعد.
